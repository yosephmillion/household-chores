# Household Chores Manager — Project Plan

## Problem

Shared households often struggle with forgotten chores and unfair
distribution of household responsibilities.

The goal of this application is to help household members organize,
distribute, and track chores.

## Target Users

The application is designed for households with multiple members.

Each household member should be able to see their assigned chores
and mark them as completed.

## Core Features

### 1. Household Members

Multiple members can belong to a household.

Each member has their own assigned chores.

### 2. Automatic Chore Rotation

Recurring chores are automatically distributed among household members.

When a recurring chore is completed, it moves to the next member in
the rotation.

### 3. Chore Management and History

The application supports:

- One-time chores
- Recurring chores
- Marking chores as completed
- Completion history
- Overdue chores
- Notifications for overdue chores

### 4. Dashboard and Calendar

The main dashboard shows:

- The current user's chores
- Household chore status
- Upcoming chores

A calendar view shows chore due dates.

## Out of Scope

The first version will not include:

- Mobile applications
- Payments
- Chat
- Gamification
- Complex permission systems
- Advanced notification infrastructure

These may be considered future improvements.

## Main User Flow

1. A household has multiple members.
2. Chores are created.
3. Recurring chores are assigned automatically using rotation.
4. A member sees their assigned chores.
5. The member completes a chore.
6. The completion is recorded.
7. For recurring chores, the chore moves to the next member.
8. Overdue chores generate a notification.
9. Members can view their chores and household status from the dashboard.
10. Members can view upcoming chores on the calendar.
